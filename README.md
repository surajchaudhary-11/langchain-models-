# LangChain Models

Practice project for working with LLMs using LangChain.

- ChatModels: OpenAI, Hugging Face API and local models
- EmbeddedModels: OpenAI embeddings for queries and documents
- LLM: basic LLM demo

## Setup
pip install -r requirements.txt
Create a .env file with your own keys (OPENAI_API_KEY, HUGGINGFACEHUB_API_TOKEN)
